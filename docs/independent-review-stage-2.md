# Независимое ревью этапов 1–2

Три ревьюера запущены без истории чата. Им переданы задача, актуальное
[ТЗ](specification.md), статья и исходники. Исходники ревьюеры не меняли.

- **Алгоритмы:** Dinic, разделители, полнота перечислителя и дерево.
  Дополнительно проверены все 33 867 графов на 1–6 вершинах; деревья — для
  всех 27 475 связных графов на 2–6 вершинах при каждом минимальном размере.
- **Инфраструктура:** сборка, конфигурация, чтение графов, CLI и формат ответов.
- **Проверки:** независимость эталона и покрытие тестов. Дополнительно проверены
  80 случайных графов на 9–10 вершинах и семейства пересекающихся клик.

Подтверждённых существенных ошибок в реализованном алгоритмическом ядре не найдено.
Ревью выявило редкие пограничные случаи округления и записи α. По решению пользователя
сохраняем простую арифметику double; усложнение для этих случаев отменено.
После отмены все три ревьюера повторно проверили затронутые части.

Между следующими итерациями ревьюеры также получают только задачу, ТЗ и код.
Приоритет — ошибки алгоритма, неполный перебор, потеря результатов и восстановление.
Незначительные замечания показываются пользователю без автоматического исправления.

Этапы 3–6 ещё не реализованы. Эта проверка не подтверждает работоспособность будущих
PDownsize, параллелизма, checkpoint и загрузчика GitHub.
