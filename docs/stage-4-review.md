# Этап 4: параллельная обработка нод

Версия 0.4.0. Один WorkerPool живёт весь запуск; число работников задаёт `threads`.
ExactSolver всегда использует переданный пул, в том числе при одном работнике.

## Выполнение

- Одна задача — одна нода дерева. Внутри неё PDownsize последовательно перебирает
  r-подмножества и проверяет пары потоками. Разбиения ноды между работниками нет.
- Координатор обходит уровни связности по убыванию. Следующий уровень начинается
  только после полного неуспеха текущего. Построение дерева последовательное.
- WorkerPool имеет submit/wait и очередь без ограничения размера.
  submit добавляет задачу под мьютексом без ожидания свободного места.
  Выполняется не больше одной задачи на работника; все комбинации заранее не материализуются.
- Первый успех сохраняет свидетель и отменяет остальные ноды. Отмена проверяется
  перед подмножеством и между парами; уже начатый поток завершается.
  Ожидающие задачи после отмены выходят без перебора.
- wait дожидается и очереди, и активных задач, затем передаёт исключение координатору.
  При ошибке submit ранее принятые задачи также дожидаются завершения: захваченные
  ссылки остаются действительными. Пул рассчитан на одного координатора.
- Если на уровне одна нода, занят один работник. Свидетель может зависеть от порядка
  выполнения, оптимальный k от числа работников не зависит.
- combination_chunk_size, диапазоны и восстановление комбинации по рангу удалены.

## Проверки

- Фиксированные ответы в `test_known_solver_answers`: ребро, путь P4, клика K4,
  цикл C4, два треугольника с общей вершиной, C6 и K3, соединённые мостом.
  Для первых пяти графов проверены все r; для последнего — r=3,6,9.
  Оптимумы и все допустимые множества вершин для этих случаев записаны вручную.
  Решатель с пулами на 1/4 работника сравнивается с этими константами,
  а не друг с другом. Перебор разрезов ниже остаётся дополнительной проверкой.

- Лексикографический перебор всех комбинаций n<=12 против битовых масок;
  число C(100,50) без переполнения.
- Независимый оракул вершинных разрезов: все связные графы до 5 вершин,
  случайные до 8, все r; сравнение последовательного и параллельного решения.
- Полный неуспех одной ноды и двух нод: точное число проверенных подмножеств
  и задач. Успех отменяет остальные ноды; следующий поиск работает полностью.
- Пул: одновременные задачи, исполнение каждой ровно один раз, повторное использование,
  исключения и завершение принятых задач в деструкторе.

Проверено после изменения: CTest 12/12 на macOS Release, Ubuntu 22.04 Release
и macOS ASan/UBSan. ThreadSanitizer: solver и parallel, 2/2 без ошибок.
Три независимых ревьюера существенных замечаний не нашли.

## Границы

Checkpoint, сохранение позиции перебора ноды, SIGINT/SIGTERM с сохранением, ZIP/resume
и GitHub остаются этапами 5–6. Длительные расчёты не запускались.
Следующий этап начинается после пользовательского ревью.
